## 一、需要优先改正

### 1. Floyd 的负环处理仍然不正确

位置：`chapter5.tex` 第 70--76 行。

当前解答是：

> 在任何时刻，若 `d[u][u]<0`，则令 `d[u][u]=-∞`。

只修改对角元不能保证把负环影响传播到所有点对，而且在某个 `k` 已经处理完后才发现 `d[k][k]<0`，还会错过以它为中间点的传播。

两点反例：

```text
1 -> 2，权 -4
2 -> 1，权 -2
```

按普通 Floyd 顺序，第 1 轮结束后才得到 `d[1][1]<0`；如果只在当前轮检查当前对角元，最后可能留下有限的 `d[1][1]`，但真实答案中四个点对都是 `-∞`。

建议改成：先完成普通 Floyd，再记录所有满足 `d[k][k]<0` 的点 `k`；对每个这样的 `k`，若 `i` 能到达 `k` 且 `k` 能到达 `j`，则令 `d[i][j]=-∞`。若题目坚持要求每一层的 `d_i`，则需要在每层额外完成相应的负环可达性传播，不能只改对角元。

### 2. 三角不等式的等号条件仍包含 `d=-∞`

位置：`chapter5.tex` 第 29--31 行。

当前前提为 `d(u,v)<+∞`，其中仍包括 `d(u,v)=-∞`。此时不存在真正取得 `-∞` 的最短路，所以“当且仅当 `w` 在某条最短路上”没有意义。

建议改为：

> 当 `|d(u,v)|<∞` 时，等号成立当且仅当存在一条经过 `w` 的 `u` 到 `v` 的最短路。

### 3. “不能再松弛即可判定等于最短路”少了源点归一化条件

位置：`chapter5.tex` 第 97--101 行。

第二段写道：若 `\tilde d\ge d`，则 `\tilde d=d` 当且仅当不能被任何边松弛。这作为独立命题不成立。例如把所有可达点的真实距离统一加 1，通常仍没有边能够松弛，但源点的估计为 1 而不是真实的 0。

应把条件写全：

> 若 `\tilde d\ge d_s`、`\tilde d(s)=0`，则 `\tilde d=d_s` 当且仅当没有边能够继续松弛。

如果这里只讨论从标准初始化出发的算法，也可以明确说明 `\tilde d(s)=0` 是始终保持的不变量。

### 4. 重赋权不能“任取起点”后直接令 `φ=d_s`

位置：`chapter5.tex` 第 226--233 行。

若 `s` 不能到达某个点，则 `d_s(v)=+∞`，表达式

```text
wφ(u,v)=w(u,v)+φ(u)-φ(v)
```

可能出现无定义的无穷量相减。因此该引理需要增加“`s` 能到达所有点”的条件。Johnson 算法的标准做法正是添加一个向所有原图顶点连 0 权边的超级源点，再从超级源点计算势函数；同时还需假设图中没有负环。

### 5. Borůvka 同权时不能无条件把每个连通块选出的边全部加入树

位置：`chapter4.tex` 第 39--43 行。

三个点组成的等权三角形时，三个单点连通块可能分别选择三条不同的边；若全部无条件加入，就会形成环。

建议补一句：把各连通块选出的候选边去重后，再用并查集只加入连接当前不同连通块的边；或者预先给边添加全局唯一的第二关键字，并说明为何候选边不会形成非平凡环。

### 6. Floyd 求最小简单环的解答尚未形成正确、完整的公式

位置：`chapter5.tex` 第 78--86 行。

当前式子中的 `u,v,x` 没有完整枚举范围，也没有说明三段拼接后为何必为简单环。在无负环图上可以根据有向图/无向图分别给标准做法；若允许负环，则讲义自己也已指出“最小简单环”会变成 NP 困难问题，因此应把“先报告负环”和“无负环后求最小环”两个阶段明确分开。

## 二、Tarjan 的 `low[v]` 版本

位置：`chapter2.tex` 第 78--111 行。

当前代码在遇到已经访问且仍在栈中的 `v` 时使用

```cpp
low[u] = min(low[u], low[v]);
```

而标准模板通常使用 `dfn[v]`。本次对 5 个点以内的所有简单有向图进行了穷举，两种版本得到的 SCC 划分均与真实强连通分量一致；没有发现反例。当前变体可以保留。

它与标准 `low` 的语义不同：

- 标准写法的 `low[u]` 可能直接指向一个仍在栈中的兄弟分支顶点，因此不一定对应 `u` 的祖先。
- 使用 `low[v]` 的变体会继续沿候选点的低链接传播，因而可以维护“能到达的最浅活动祖先”这一更强的量。

建议在练习后补一小段证明或明确不变量。否则读者容易把非标准代码当成笔误。还应把 SCC 证明中的“在 `dfs(u)` 结束后被发现”改成“在 `dfs(u)` 返回前被发现”，时间顺序才准确。

## 三、需要补充条件或收紧表述

### 1. Kruskal 同权变换有一个笔误

位置：`chapter4.tex` 第 58 行。

当前写成

```tex
\tilde w_{e_i}=\tilde w_{e_i}\cdot |E|+i
```

右侧第一个量应为原权值：

```tex
\tilde w_{e_i}=w_{e_i}\cdot |E|+i.
```

并约定边编号为 `0,...,|E|-1` 或说明当前编号范围不会破坏原来的主关键字顺序。

### 2. Floyd 初始化还缺实现约定

若允许重边，应初始化为 `d[u][v]=min(d[u][v],w)`；若使用整数哨兵 `INF`，转移前应判断两段均可达，或保证加法不会溢出。允许零条边时再设 `d[i][i]=0`。

### 3. 理论最快复杂度需要注明模型

`chapter5.tex` 第 144 行所引 2026 年算法针对的是“实数非负权有向图”，复杂度公式与原论文摘要一致。第 164 行的两项负权 SSSP 复杂度也与所引论文一致。但“直到某年最快”容易忽略整数权、无向图、随机化与计算模型的差别，建议改成：

> 对实数边权有向图，在相应论文采用的理论计算模型下……

资料：

- <https://arxiv.org/abs/2602.07868>
- <https://arxiv.org/abs/2304.05279>
- <https://arxiv.org/abs/2607.19346>

### 4. 素数间距公式本身可以保留

当前下界

```text
Ω(log n log log n log^(4)n / log^(3)n)
```

以及经典的 `O(n^0.525)` 上界，与 Ford--Maynard--Tao 对已有结果的综述一致；该文也把 Cramér 猜想表述为最大间距 `asymp log² n`。因此旧复审中要求删除 `Theta(log²n)` 的意见不再保留。

资料：<https://arxiv.org/abs/1511.04468>

不过“在 OI 常用范围中区间不会很大”仍不是独立的复杂度证明。最好注明本题实际的 `n` 上限和最大实测/可证明间距，再说明暴力 MST 的最坏工作量。

### 5. 隐式连边“总是不劣”仍说得过满

位置：`chapter5.tex` 第 309--311 行。

隐式算法通常在渐近规模上不劣于把所有边完全展开，但实际常数还取决于查询数据结构、重复生成、缓存局部性和实现复杂度。建议把“复杂度和常数上总是不劣”改成“通常能避免显式建图的额外规模，渐近复杂度往往不劣；实际常数需视实现而定”。

### 6. 差分约束极值应说明无界

位置：`chapter5.tex` 第 339--351 行。

`d(0,i)=+∞` 表示 `x_i` 没有有限上界；`d(i,0)=+∞` 表示没有有限下界。当前解答最好把这两种情况和系统无解的情况分别写出。

### 7. 代数路径的第二维需要排除或处理零环

位置：`chapter5.tex` 第 398--418 行。

“无负环”仍允许第一维为 0 的环。此时最短路图可能有环，最短路计数可能为无穷，第二维半环的无限和也未必有定义。应补充以下任一条件：

- 第一维严格正，使最短路图为 DAG；
- 先对 0 环 SCC 缩点，并说明 SCC 内第二维如何处理；
- 使用具有适当闭包/Kleene 星运算的半环。

“前 `k` 短路半环”还应定义少于 `k` 个元素时如何补 `∞`，以及加法零元和乘法单位元。

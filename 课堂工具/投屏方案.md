mac + android 方案，mac 应该也能换成 win/linux。

首先安装 scrcpy

在 android 设备上打开 usb 调试，可能还需要开启：usb调试（安全设置）、在仅充电时允许usb调试 这种选项

每次使用前先连上usb，然后运行 `scrcpy` 即可实现有线连接的投屏。

连完 usb 之后也可以进行无线投屏，此时需要保证设备在同一网络下，运行 `scrcpy --tcpip` 之后就可以拔掉线了。

默认参数下无线投屏的延迟较大，可以添加以下参数来以降低画质的代价降低延迟：

```shell
# 去掉音频；分辨率的长边限制到 1280（保持纵横比）；码率限制到 2M；最大帧率限制到 60
--no-audio -m 1280 -b 2M --max-fps=60
```

如果网还是差可以进一步降低到

```shell
-b 1M --max-fps=30
```
